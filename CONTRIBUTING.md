# Contributing

Install the package with `python -m pip install -e '.[notebooks]'` and use the notebook controls to select a reproducible experiment.

Numerical changes should state their mathematical effect and compare matched initial particles, seeds, neural initialization, tangent-coordinate selection, dtype, SVD cutoff, and reference solver. Treat accumulated particle evolution and periodic neural-map refitting as distinct adaptation rules.

Retain raw arrays and settings with numerical claims. Label reduced execution checks as demonstrations. Avoid committing generated run folders or archives.
